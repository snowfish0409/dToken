# dToken Chrome Apps

Chrome App Mode versions of:

- `user`
- `provider-console`

Double-click the `.app` files to run them with Google Chrome wallet extensions.

Ports:

- User: `http://127.0.0.1:8789/`
- Provider Console: `http://127.0.0.1:8792/`

Do not commit `node_modules`, logs, pid files, or local runtime data.
